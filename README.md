# Zamindar-Hunt
A 3D survival horror web game set in an eerie abandoned Bangladeshi village mansion. Escape the roaming Jinn by finding sacred protective scriptures.

"Zamidar Haunt" is a first-person 3D survival horror web game built with React, TypeScript, and modern web technologies. Explore a dark, decaying traditional Bangladeshi village mansion, evade a terrifying roaming Jinn, and collect five sacred protective scriptures to break the curse and escape!

## 🌟 Features
* **Atmospheric Horror Setting:** Traditional 1990s Bangladeshi Zamidar Bari vibe.
* **Bilingual Support:** Fully playable in both English and Bengali (বাংলা).
* **Survival Mechanics:** Flashlight navigation, creeping Jinn AI, and hidden scripture hunting.
* **Modern Tech Stack:** Built using React and TypeScript.

## 🚀 How to Play
1. Enter the eerie mansion.
2. Use your flashlight to navigate dark corridors.
3. Find all hidden protective scriptures.
4. Unlock the escape gate before the Jinn catches you!
